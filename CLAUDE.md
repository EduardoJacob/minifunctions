# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Package Overview

**minifunctions** is an R package containing ~35 standalone utility functions across these domains:
- Number Theory (continued fractions, digital roots, Euclid numbers, multiplicative order)
- Combinatorics (derangements, permutations, powersets)
- Algebra (polynomial fitting, parabola analysis, Newton-Raphson root finding)
- Base conversions (decimal/fractional bases)
- Data visualization (HTML table rendering, image grids)
- RStudio integration utilities

## Architecture

### Directory Structure
```
minifunctions/
├── R/                    # Source files (one per function)
│   ├── continuedfraction.R
│   ├── derangements.R
│   ├── printdataframe.R
│   └── ...
├── tests/testthat/       # Unit tests
├── man/                  # Generated documentation (.Rd files)
├── DESCRIPTION           # Package metadata
├── NAMESPACE             # Exported functions (auto-generated by roxygen2)
├── README.Rmd            # Documentation source
└── SETUP.R               # Development setup script
```

### Function Pattern
Each R file contains exactly one exported function following this pattern:
```r
#' Function Title
#'
#' @param arg1 Description of argument 1
#' @return Return value description
#' @export
#'
#' @examples
#' \dontrun{
#' example()
#' }
function_name = function(args) {
  # Implementation
}
```

### Key Dependencies (from DESCRIPTION)
- **Core**: dplyr, gmp, gtools, httr2, magick, polynom, purrr, stringr
- **High-precision**: Rmpfr, numDeriv
- **Visualization**: kableExtra, knitr, RColorBrewer, oro.dicom
- **Math**: numbers, primes, TeachingDemos


## Common Development Tasks

### 1. Add a new function
```bash
# Create new R file in R/ directory with roxygen2 comments
# Then document:
devtools::document()

# Run tests
devtools::test()
```

### 2. Rebuild documentation
```r
devtools::document()
```

### 3. Install locally for development
```r
devtools::load_all()
# or
pkgload::load_all()
```

### 4. Run a single test
```r
testthat::test_file("tests/testthat/test-<functionname>.R")
```

## Code Style Notes

- Functions use `=` for assignment (not `<-`)
- Uses pipe operator `|>` for data transformations
- Character vectors use `c()` constructor
- High-precision arithmetic uses `gmp::as.bigq()` and `gmp::as.bigz()`
- 256-bit precision via `Rmpfr::mpfr(..., precBits = 256)`
- HTML tables use `knitr::kable()` with `kableExtra::kable_styling()`

- `images/` folder

## Important Notes

1. **High-precision arithmetic**: Many functions use `gmp` package for exact rational arithmetic to avoid floating-point errors
2. **HTML output**: Functions like `printdataframe()` return HTML tables that render in RStudio viewer
3. **API dependencies**: `serpapi()` requires `SERPAPI_KEY` environment variable
4. **Test coverage**: Tests are minimal; most functions have examples in roxygen comments but no dedicated test files
